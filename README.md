# IT 二部工单中心系统

## 快速启动（开发环境）

```bash
# 后端
cd backend
cp .env.example .env   # 首次运行需要，填入当曲云账号密码等配置
npm install
npm run dev             # 默认监听 4000 端口

# 前端（新开一个终端）
cd frontend
npm install
npm run dev              # 默认监听 5173 端口
```

## 让同事通过局域网访问你本机登录

系统当前的登录方式是「姓名 / 拼音码」匹配（无需密码），所以只要同事的电脑能连到你本机的服务，就可以直接用自己的账号登录，不需要额外部署服务器。

1. 确认你和同事的电脑在**同一个局域网**（同一个公司 WiFi / 交换机）。
2. 按上面的步骤在你本机启动好后端（4000 端口）和前端（5173 端口）。
3. 前端启动后，终端会打印出 `Network:` 开头的地址（Vite 已配置 `host: true` 监听局域网），例如：

   ```
   ➜  Local:   http://localhost:5173/
   ➜  Network: http://192.168.1.23:5173/
   ```

   同时后端启动日志也会打印出局域网访问地址，两者的 IP 应该一致。
4. 把 `Network` 那一行的地址发给同事，让他们在浏览器里打开，然后用自己的姓名或拼音码登录即可。
   **注意：一定要发前端（5173）的地址，不要发后端（4000）的地址** ——4000 端口只有 `/api/*` 接口，直接打开会看到 `Cannot GET /`。
5. 如果同事打不开：
   - 检查你电脑的防火墙是否放行了 5173、4000 端口（Windows「防火墙高级设置」新建入站规则；Mac 系统偏好设置里允许对应端口）。
   - 确认双方确实在同一网段（能否互相 `ping` 通）。
   - 公司如果用的是访客网络 / 有 AP 隔离，同一 WiFi 下设备之间也可能无法互访，需要换成同一有线/办公网段。

> 注意：这种方式只适合临时内部联调、演示使用。你的电脑关机或前后端进程退出后，同事就无法访问了；如果需要长期稳定使用，建议部署到一台常驻运行的服务器上（后端 `npm run build && npm start` 会顺带托管 `frontend/dist` 静态资源，见 `backend/src/index.ts`）。
